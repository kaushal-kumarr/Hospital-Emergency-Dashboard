# 🏥 Hospital Emergency Room Dashboard

## 📊 Project Overview

This project is an Excel-based dashboard designed to analyze hospital emergency room data. It provides insights into patient flow, wait times, and overall performance.

## 📁 Files Included

* 📄 Hospital ER Dashboard.xlsx → Main dashboard file
* 📊 Hospital Emergency Room Data.csv → Raw dataset
* 🖼 Screenshot.png → Dashboard preview
* 🏥 hospital-logo1.jpg → Logo used in dashboard

## 🔑 Key Features

* Total number of patients analysis
* Average wait time tracking
* Patient satisfaction score
* Gender-wise patient distribution
* Age group analysis
* Department referral insights

## 🛠 Tools Used

* Microsoft Excel
* Pivot Tables
* Charts & Graphs
